## ✨ Features

### 🔢 Number System Converter
- Decimal ↔ Binary
- Decimal ↔ Octal
- Decimal ↔ Hexadecimal
- Binary ↔ Octal
- Binary ↔ Hexadecimal
- Octal ↔ Hexadecimal
- Swap source and target bases
- Input validation
- Copy converted result
- Enter key support

### 🧮 Calculator
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal values
- Backspace
- Clear
- Keyboard support
- Divide-by-zero protection
- Copy result

### 📱 Interface
- Responsive on desktop, tablet and mobile
- Clean minimal UI
- Smooth section navigation
- No framework or build step
- Pure HTML, CSS and JavaScript

## 🚀 How to Use

### Converter
1. Enter a whole number.
2. Select the number system to convert from.
3. Select the target number system.
4. Press **Convert**.
5. Use **Copy** to copy the result.

Example:

```
Value: 255
From: Decimal
To: Hexadecimal

Result: FF
```

### Calculator
Use the on-screen keys or your keyboard.

Keyboard shortcuts include:

```
0–9     Numbers
.       Decimal point
+ - * / Operators
Enter   Calculate
Backspace   Delete
Escape      Clear
```
